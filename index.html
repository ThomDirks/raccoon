Two tools

One for making images out of the game, one for checking them before they go live. Both work offline once the page has loaded.

Photo Booth

Load a model exported from the Creator's Kit plugin and save it from any angle, cleanly cut out.

  • Turn and tilt freely. The light follows the camera, so every angle matches.
  • Put two models in one scene, each with its own animation, spaced in game tiles.
  • Save transparent PNGs, PNG sequences for Premiere, or looping GIFs, together or one model at a time.

Thumbnail Bench

See your thumbnails the way viewers meet them: small, fast, and surrounded by other people's videos.

  • Mix your thumbnails into a long feed of competitors' videos, one of yours every few.
  • PC, tablet, phone and TV layouts, each with that device's own preview behaviour.
  • Point it at your export folder, and new versions show up while you work in Photoshop.

Getting models out of the game

The Photo Booth reads the files that the Creator's Kit plugin for RuneLite exports. Setting it up takes a few minutes.

  1. Install Creator's Kit

    Find it in RuneLite's Plugin Hub and switch it on.

  2. Place a copy

    Add an object, store your character or an NPC into it, and Ctrl + click the ground to place it.

  3. Export 3D

    Right-click the placed copy and choose Export 3D. The file lands in .runelite/creatorskit/blender-models.

  4. Load it

    Drop the .json file onto the Photo Booth. For an animation, export each frame and load them all at once.

For animation frames, set Anim ID to the animation and Frame to 0, export, then Frame 1, 2 and so on. Name the files in order. The Photo Booth needs the JSON export, so switch the exporter back if it's set to OBJ.
